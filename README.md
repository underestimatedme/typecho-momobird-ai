# MomoBird AI for Typecho

把 Typecho 的公开文章同步到 MomoBird 控制台的项目里，让这些文章可以在「问答调试」和网站问答助手里被提问、被引用；也可以把 MomoBird 问答助手直接挂到博客前台。

本插件属于 MomoBird 专业版功能，首次连接自动开始 7 天试用。

## 功能

- 同步公开普通文章（`post + publish`，且没有设置密码），每篇文章在项目里是一篇文档，由服务端统一切块和索引。
- 文章发布、更新时自动推送；转为私密、隐藏、待审核或被删除时自动从知识库下线。
- 后台一键全量同步，并清理博客里已经不存在或不再公开的文章。
- 失败的推送可以一键重试。
- 可选：在博客前台显示 MomoBird 问答助手，读者可以直接提问。
- Typecho 文章索引完成后自动对线上助手生效，不需要在控制台重新发布。

独立页面（page）、草稿、附件、评论不会同步。

## 环境要求

- Typecho 1.2.x
- PHP 7.2 或更高版本
- PHP cURL 与 mbstring 扩展
- MySQL；同步表同时提供 SQLite 兼容结构
- Typecho 服务器可以访问 `https://api.valley.atlaspaces.com`

## 安装

1. 在 MomoBird 控制台（https://momobird.atlaspaces.com）打开或新建一个项目，进入「知识 → 新增来源 → Typecho 博客」，填写来源名称和博客地址。
2. 复制页面上显示的**连接密钥**（以 `mbk_` 开头，只显示这一次），并下载插件包 `MomoBirdAI-0.2.3.zip`。
3. 解压后把 `MomoBirdAI` 目录上传到 Typecho 的 `usr/plugins/`。
4. 在 Typecho 后台「控制台 → 插件」中启用 **MomoBird AI**。
5. 打开插件设置，填写连接密钥并保存。
6. 进入「控制台 → MomoBird 同步」，点击「测试连接」，确认项目名称和权益状态，然后点击「一键全量同步」。

启用插件会创建带 Typecho 数据表前缀的 `momobird_sync` 表，只保存同步状态和脱敏错误，不保存文章正文。

## 配置

| 配置 | 说明 |
| --- | --- |
| 自动同步 | 开启后，在文章发布、修改、删除时自动推送；关闭后仍可在后台手动全量同步和重试 |
| MomoBird Base URL | 默认 `https://api.valley.atlaspaces.com`，通常不需要修改；只有本机地址允许 HTTP |
| 连接密钥 | 控制台生成的 `mbk_` 密钥；留空保存会保留已保存的密钥（设置页会显示已保存密钥的前缀），升级插件不需要重新填写 |
| 请求超时 | 2–30 秒，默认 10 秒 |
| 在前台显示问答助手 | 打开后插件会在博客页面底部加载 MomoBird 助手 |

连接密钥只在服务端使用，不会出现在博客前台；设置页不会回显已保存的密钥。密钥仍保存在 Typecho 的配置表中，数据库备份也应按敏感数据保护。如果密钥泄露，在控制台该来源下「重新生成」，再把新密钥填回插件。

## 前台问答助手

- 第一次打开时，MomoBird 会自动把博客域名加入「允许的来源」；如果网站接入还没发布过，会自动发布一次。
- 如果还没有任何文章完成索引，会提示「请先完成一次全量同步」。不需要再手动保存：全量同步结束时插件会自动再开启一次；索引还没完成的话，之后有人访问博客时每 10 分钟重试，直到开启成功。
- 如果你在控制台里关闭了网站接入，插件不会自动重新开启。
- 如果你在控制台撤销了网站接入的发布，插件不会自动重新上线，需要在控制台重新发布。
- 插件把助手状态缓存在本地，读者访问页面时不会请求 MomoBird；缓存超过 10 分钟会在页面发送给读者之后后台刷新，所以状态变化（例如到期、在控制台关闭）最多需要几分钟才会反映到前台。

## 专业版与试用

- 首次在控制台创建 Typecho 来源时开始 7 天试用。
- 试用或专业版到期后：新文章不再同步，前台助手隐藏；已经同步的文章仍可以在控制台问答调试中使用。
- 到期后文章转为私密或被删除时，插件**仍会**把它从知识库下线，不会因为到期而残留。
- 后台「MomoBird 同步」页面显示当前权益和到期时间。
- 开通或续费：在 MomoBird 控制台知识页点「兑换码」，输入月卡（31 天）或年卡（366 天）兑换码；仍在有效期内会从到期日顺延。

## 同步行为

### 发布和更新

文章正式发布或重新发布后，插件读取数据库中的最终版本，转换为纯文本（保留标题层级）后整篇推送。内容没有变化时不会重复推送。同步失败不会撤销或阻止 Typecho 发布；后台会显示错误通知并保留失败状态。

### 转为非公开或删除

文章变为私密、隐藏、待审核或被删除时，插件请求 MomoBird 下线该文章。即使本地没有同步记录，也会发送下线请求，保证非公开内容不会残留。

### 一键全量同步

浏览器分批处理公开文章（每批最多 20 篇），因此不依赖 cron，也不会用一个超长 PHP 请求同步整个站点。全部批次成功后，插件会对照 MomoBird 上的文章列表，下线博客里已经不存在或不再公开的文章。

单篇文章被服务端拒绝（例如正文超过 2 MiB）只会记为该篇失败，不会中断全量同步；网络错误或权益到期会中断本轮，且不会执行清理。请在全量同步过程中保持后台页面打开。

## 停用与数据保留

停用插件时：

- 不删除 MomoBird 上的知识；
- 不删除本地同步表；
- 把插件配置备份到独立的 Typecho 配置项，再次启用时恢复连接密钥。

如需彻底移除，先在 MomoBird 控制台删除对应的 Typecho 来源，再停用插件并删除同步表和备份配置。

## 故障排查

| 状态或现象 | 检查项 |
| --- | --- |
| 401 | 连接密钥缺失、复制错误、已被重新生成或吊销，或者控制台里的来源已被删除 |
| 402 `PLAN_REQUIRED` | 试用或专业版已到期；新文章不会同步，删除仍会生效。在控制台用兑换码开通后，点「一键全量同步」补齐 |
| 409 `WIDGET_NOT_READY` | 还没有任何文章完成索引，先全量同步，稍后再打开前台助手 |
| 413 / `PAYLOAD_TOO_LARGE` | 单篇文章正文超过 2 MiB |
| `UNSUPPORTED_CONTENT` | 文章正文为空或包含无法处理的内容 |
| 502 / 504 | MomoBird 或上游服务临时不可用；插件会自动重试一次 |
| timeout | Typecho 主机无法访问 MomoBird，或超时设置过短 |
| 发布成功但同步失败 | 前往「MomoBird 同步」查看失败计数并点击「重试失败项」 |
| 前台没有出现助手 | 检查插件设置是否打开前台助手、权益是否有效、控制台网站接入是否被撤销；状态变化最多需要几分钟生效 |

错误通知和状态表不会记录连接密钥、文章正文或完整的服务端响应。

## 开发验证

```bash
php tests/run.php
find . -name '*.php' -not -path './.git/*' -not -path './.worktrees/*' -print0 | xargs -0 -n1 php -l
node --check assets/admin.js
node --test tests/admin-panel.test.mjs
bash scripts/package.sh
```

`scripts/package.sh` 生成 `dist/MomoBirdAI-0.2.3.zip`，压缩包顶层目录为 `MomoBirdAI/`，不包含测试和文档。

## 安全说明

- 所有 MomoBird 请求均从 PHP 服务端发出，前台只输出问答助手的公开项目 ID。
- 后台操作要求管理员权限和 Typecho CSRF 校验。
- 生产 Base URL 必须使用 HTTPS；只有 localhost 和回环地址可使用 HTTP。
- 客户端限制响应体大小并保持 TLS 证书校验。
- 项目中不应提交任何真实生产凭据。
